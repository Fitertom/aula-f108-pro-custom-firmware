# 1. Прошивка кастомной версии

Перед началом прочитай [05-recovery.md](05-recovery.md).

## Что нужно

- AULA F108 Pro, подключённая USB-кабелем прямо к ПК (по возможности без хаба). Официальная утилита шьёт только по кабелю,
  через Bluetooth и донгл 2.4G она не работает.
- Официальный `AULA_F108_Pro_Firmware.exe` со страницы загрузок производителя для F108 Pro.
- Python 3.8+ на Windows.
- Заряженная клавиатура. Не шей при почти пустой батарее.

## Шаг 1. Проверь, что файл правильный

Патч сделан под одну конкретную версию прошивки. Патчер достаёт образ из твоего exe и сравнивает его SHA-256 со значением
`stock_image_sha256` из `firmware/patch_data.json`. Если не совпало, он останавливается и ничего не пишет. Не пытайся обойти
проверку: патч по фиксированным адресам в другой версии прошивки её испортит.

SHA-256 всего exe можно сравнить с `stock_exe_sha256` из того же файла (PowerShell: `Get-FileHash .\AULA_F108_Pro_Firmware.exe`).
Другой exe может содержать тот же образ, поэтому решает проверка образа.

## Шаг 2. Создай свою утилиту

```
python firmware\apply_patch.py C:\путь\AULA_F108_Pro_Firmware.exe
```

Результат: `AULA_F108_Pro_Firmware_CUSTOM.exe` в той же папке (`-o имя.exe` задаёт другое имя). Исходный файл не меняется.
Скрипт сам проверяет записанный exe, считывая образ обратно.

Если нужен сырой образ для другой утилиты прошивки, добавь `--bin-out patched_image.bin`.

## Шаг 3. Прошивка

1. Закрой программу-драйвер AULA и всё, что обращается к клавиатуре (OpenRGB и другие RGB-программы).
2. Подключи клавиатуру кабелем. Если у модели есть переключатель типа подключения, выбери провод.
3. Запусти `AULA_F108_Pro_Firmware_CUSTOM.exe`. Это обычное окно официальной утилиты, но с пропатченным образом.
4. Нажми Start. Ничего не трогай, пока не появится "Update successfully".
5. Клавиатура перезапустится. Первый запуск может занять немного времени.

После прошивки режимы подсветки и часть настроек сбрасываются на значения по умолчанию, как после любого обновления. У автора
GIF-анимации в клавиатуре сохранились, но свои важные данные лучше сохранить отдельно.

## Шаг 4. Проверка

- Зона над стрелками показывает градиент заряда (от красного к зелёному).
- Покрути колёсико на главном экране: после него должна появиться страница SIDE LIGHT, см. [02-menu.md](02-menu.md).

## Вернуть заводскую

Запусти оригинальный, неизменённый `AULA_F108_Pro_Firmware.exe` так же. Это полностью вернёт оригинальную прошивку.
