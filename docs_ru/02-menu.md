# 2. Меню на экране

Экраном управляют колёсиком. В заводской прошивке страницы идут по кольцу: главный экран, дальше другие страницы, потом
страница GIF и так далее. Патч добавляет две страницы между главным экраном и GIF:

```
главный экран  ->  SIDE LIGHT  ->  ARROWS  ->  GIF  ->  ...
```

Покрути колёсико в ту сторону, которой уходишь с главного экрана на следующую страницу, и попадёшь в SIDE LIGHT.

## Один экран, четыре кружка

На обеих страницах четыре кружка, под каждым короткое значение.

```
 SIDE LIGHT                      ARROWS
 EFFECT  COLOR  SPEED  BRIGHT    MODE    COLOR  SPEED  BRIGHT
```

- Вращение колёсика: выделение переходит между кружками. Если крутить в ту сторону, с которой вошёл, выделение идёт справа налево
  по кружкам, а ещё один шаг уводит на следующую страницу кольца. В другую сторону идёшь обратно, за первым кружком возвращаешься
  на предыдущую страницу.
- Нажатие: выделенный кружок становится активным (кольцо становится голубым, в заголовке видно, что ты меняешь).
- Вращение при активном кружке: значение меняется и применяется сразу.
- Нажатие ещё раз: возврат к выбору кружка.
- Серый кружок с надписью NONE: у текущего эффекта или режима такой настройки нет. Нажатие на него показывает короткую подсказку.

## SIDE LIGHT (две боковые полосы)

| Кружок | Значения |
|---|---|
| EFFECT | шесть заводских эффектов боковых полос |
| COLOR | цвет палитры 1-8 или AUTO. У эффектов 3 и 6 выбора цвета нет (NONE) |
| SPEED | 1-6 |
| BRIGHT | 1-6 |

Страницы вызывают те же внутренние функции, что FN-клавиши заводской прошивки, поэтому результат тот же, что при смене боковой
подсветки через FN (включая то, что заводская прошивка сама сохраняет).

## ARROWS (зона над стрелками)

| Режим | Что делает | COLOR | SPEED | BRIGHT |
|---|---|---|---|---|
| BATTERY | градиент заряда, мигает при заряде ниже 20 процентов (по умолчанию) | NONE | NONE | да |
| STOCK | заводское поведение зоны | NONE | NONE | NONE |
| SOLID | один цвет | да | NONE | да |
| BREATH | дыхание одним цветом | да | да | да |
| RAINBOW | бегущая радуга | NONE | да | да |
| OFF | зона выключена | NONE | NONE | NONE |

Настройки ARROWS живут только в оперативной памяти. После выключения клавиатуры или отключения кабеля зона вернётся в BATTERY.
Так сделано намеренно, чтобы не писать флеш при каждом изменении.

## Колёсико в режиме громкости

Клавиша FN переключает колёсико между навигацией по меню и громкостью ПК (заводское поведение). В режиме громкости вращение меняет
громкость, а нажатие теперь Play/Pause (раньше Mute).

## Заметки

- Если при открытой нашей странице нажать комбинацию, которую обрабатывает сама прошивка (например FN и клавишу эффекта), меню
  закроется и вернётся заводской экран. Так задумано.
- Когда клавиатура в режиме прямого RGB (работает OpenRGB), зона над стрелками и боковые полосы управляются компьютером, поэтому
  настройки меню не видны, пока OpenRGB не отпустит клавиатуру.
