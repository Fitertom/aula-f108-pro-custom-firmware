# 4. Python-утилиты

Нужны Python 3.8+ и модуль `hid` (`pip install hidapi`), а также кастомная прошивка. Закрой OpenRGB и драйвер AULA: две программы,
пишущие в одну клавиатуру, конфликтуют.

| Утилита | Назначение |
|---|---|
| `tools/direct_rgb.py` | Прямой RGB по кабелю. |
| `tools/direct_rgb_dongle.py` | Прямой RGB через донгл 2.4G. |
| `tools/rgb_studio.py` | Небольшая программа на Tk: рисование по клавишам и зонам, проверка карты LED (использует `tools/keymap.json`). |
| `tools/battery.py` | Чтение заряда (через донгл; с `--list` показывает HID-интерфейсы). |

## direct_rgb.py (кабель)

```
python direct_rgb.py zones            # тест 5 с: боковые полосы красная и синяя, зона над стрелками, остальное тускло-серое
python direct_rgb.py rainbow          # бегущая радуга по всем 147 LED, Ctrl+C - выход
python direct_rgb.py solid 255 0 0    # один цвет на 5 с
python direct_rgb.py off              # выйти из прямого режима
```

При выходе утилита отпускает прямой режим, и клавиатура возвращается к заводской подсветке. Если процесс убит без этого, клавиатура
вернётся к ней сама примерно через 1,3 с без кадров.

## direct_rgb_dongle.py (2.4G)

Клавиатура должна быть в режиме 2.4G, донгл подключён.

```
python direct_rgb_dongle.py zones
python direct_rgb_dongle.py rainbow [пауза_мс]
python direct_rgb_dongle.py solid R G B
python direct_rgb_dongle.py fps [пауза_мс]     # сколько полных кадров в секунду проходит по радиоканалу
python direct_rgb_dongle.py off
```

## Индексы светодиодов

В прошивке 147 ячеек LED. Клавиши используют индексы из `keymap.json`. Зона над стрелками: 76, 77, 78, 79, 83 (слева направо), у неё
красный и зелёный поменяны местами. Боковые полосы: 126-132 (левая, от дальнего к ближнему) и 133-139 (правая, от ближнего к
дальнему). Индексы 140-146 физических светодиодов не имеют.

Форматы пакетов описаны в [../docs/06-protocol.md](../docs/06-protocol.md) (на английском). Комментарии в части скриптов на русском.
